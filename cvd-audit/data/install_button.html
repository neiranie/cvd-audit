Install the "Capture colors" button

Drag the blue button below to the bookmarks bar in Chrome (the row under the address bar). Hold the mouse button, move, release.

Capture colors

If the bookmarks bar is not visible, press Ctrl+Shift+B.

Once installed, open a Shopee page in Chrome and click Capture colors in the bookmarks bar. Type the page type (for example home), press OK, and the file is saved to your Downloads folder.
